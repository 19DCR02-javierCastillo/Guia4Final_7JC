  1. Dominio

    2. En HTML, el término "dominio" se refiere al nombre de dominio web, que es la dirección fácil de recordar para un sitio web en internet

  2. sub-dominio

    3. Los subdominios son parte de la estructura de nombres de dominio (DNS) y no son parte del lenguaje de marcado HTML

  3. URL

    4. dirección que identifica un recurso único en la web, como una página web, una imagen o un archivo.

  4. DNS

    5. DNS es la sigla de "Domain Name System", que es el sistema que traduce los nombres de dominio (como www.ejemplo.com) a direcciones IP (como 192.168.1.1), que son necesarias para que los navegadores puedan acceder a un sitio web

  5. hosting

    6. El término "hosting" en HTML, o más precisamente en el contexto de la web, se refiere al servicio de alojamiento web

  6. FTP

    7. protocolo de red utilizado para transferir archivos entre un cliente y un servidor

  7. HTTP

    8. es el protocolo que se utiliza para transferir documentos hipermedia, como HTML, a través de la World Wide Web

  8. HTTPS

    9. HTTPS en HTML significa Hypertext Transfer Protocol Secure.

  9. W3C

    10. es una organización internacional que desarrolla y publica estándares para la web, incluyendo HTML

  10. UTF-8

    11. codificación de caracteres más común, que indica cómo se representan los caracteres en un documento

  11. HTML5 y su estructura

    12. es la última versión del lenguaje de marcado de hipertexto, HTML, utilizado para estructurar y presentar contenido en la web
